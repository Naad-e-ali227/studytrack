# StudyTrack

A simple command-line study session tracker built with Python.

## Features

- Add study sessions
- View saved sessions
- Edit sessions
- Delete sessions
- Track total study time
- Track study time by subject
- View weekly study statistics
- Automatically save data using JSON

## Technologies

- Python
- JSON

## How to run

1. Make sure Python 3 is installed.
2. Open the project folder in VS Code.
3. Run:

```bash
python3 main.py
